A **program** is a list of instructions for a computer. Python is a language for writing those instructions. It reads them from top to bottom and does exactly what they say: nothing more, nothing less.

That last part matters. A person can guess what you meant; Python can't. Most of learning to program is learning to say exactly what you mean.

## Showing something on the screen

Here is a complete Python program, one line long:

```python
print("Hello!")
```

When it runs, the screen shows:

```
Hello!
```

Three things are going on in that line:

- `print` is the name of the instruction. It means "show this on the screen". It is written in lowercase letters.
- The round brackets `( )` hold *what* to show.
- The quotes `" "` mark the start and end of a piece of text. Python shows what is between them, but not the quotes themselves.

## Running code

Below this lesson is an editor that already holds this line. Press **Run** (or Ctrl+Enter, Cmd+Enter on a Mac) and the result appears in the output box underneath.

Your code runs right here in your browser. The very first run takes a few seconds while Python starts; after that it is almost instant.

Now change the words between the quotes and run it again. Try your name, a whole sentence, or an emoji. You can't break anything: **Reset to starter code** always brings the original back.

## Recap

- A program is a list of instructions that Python follows from top to bottom, exactly as written.
- `print()` shows what's inside its brackets on the screen; text goes between quotes.
- Press **Run** (or Ctrl+Enter) to run your code and see the result in the output box.
