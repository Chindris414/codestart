---
title: Print a name card
---
Make your program show this card, line for line:

```
====================

  HELLO, my name is
  Sam

====================
```

That's 6 lines: a line of 20 `=` signs, an empty line, two lines that each start with two spaces, another empty line, and the 20 `=` signs again.

The first line is already done for you.
