---
title: Step counter
---
A step counter starts the day at 0. Under each comment, add one line that updates `steps` with `+=`, so the program shows:

```
Morning: 1200
Afternoon: 4700
Evening: 5500
```

That's 1200 steps in the morning, 3500 more in the afternoon and 800 more in the evening. Let Python do the adding.
