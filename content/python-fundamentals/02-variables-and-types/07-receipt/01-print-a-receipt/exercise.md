---
title: Print a receipt
---
Using the variables in the starter code, make the program show this receipt:

```
CodeStart Stationery
------------------------
Notebooks: 3 x 4 = 12
Pens: 5 x 2 = 10
------------------------
Total: 22
Paid: 50
Change: 28
```

Rules:

- Work out every number on the receipt from the variables. Don't type `12`, `10`, `22` or `28` yourself.
- The dashed lines have 24 dashes each; make them with `*`.

To check your program really uses the variables, change `pens` to `6` and run it again. The pens line, the total and the change should all update. Change it back to `5` before you finish.
